# BrodChip's Key Macro

A lightweight desktop macro tool for creating custom keybind-based quick messages. It focuses on speed, simplicity, and easy access to repetitive text inputs.

---

## Features

- Custom keybind macros
- Quick message sending
- Pre-Key and Post-Key support
- Auto-saving system
- Simple modern UI
- Runs in the background while active

---

## Installation

1. Download the latest release `.exe`
2. Run the application
3. The app will automatically create a `data.json` file

> Do not delete `data.json` because it stores all your saved macros and settings.

---

## How to Use

1. Open **BrodChip's Key Macro**
2. Click **New Key Macro**
3. Enter:
   - Your message
   - A keybind to trigger it (example: `CTRL+F`, `X+E`, etc.)
4. Click **Save**

---

## Pre-Key & Post-Key

The app supports optional key actions before and after sending a message:

- **Pre-Key**: Pressed before the message is pasted
- **Post-Key**: Pressed after the message is sent

You can enable or disable these using the switches in the app.

---

## Saving System

All macros are automatically stored in: data.json. This file saves all your macros, keybinds, and settings so they are automatically loaded the next time you open the application.
